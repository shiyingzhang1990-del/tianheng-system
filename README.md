# 天衡系统

一个基于 AI 的智能文档管理和问答系统。

## 🚀 快速开始

### 在本机使用

双击 `启动天衡系统.command` 即可启动（首次需要几分钟安装依赖）

或在终端运行：
```bash
bash start.sh
```

### 打包分享给其他人

运行打包脚本：
```bash
bash 打包项目.sh
```

会生成一个 `.zip` 文件，将其分享给其他人即可。

## 📖 详细文档

- **部署指南：** 查看 `部署指南.md` 了解如何在新电脑上部署
- **启动说明：** 查看 `启动说明.txt` 了解不同启动方式
- **常见问题：** 所有常见问题和解决方案都在 `部署指南.md` 中

## 📋 系统要求

- Python 3.8+
- 5GB 磁盘空间（包括 AI 模型）
- 首次启动需要联网下载模型

## 🔑 关键依赖

- Flask - Web 框架
- sentence-transformers - AI 文本嵌入模型
- chromadb - 向量数据库
- PyTorch - 深度学习框架

所有依赖会在首次启动时自动安装！

## 📡 访问地址

启动后访问：http://localhost:5001

## ⚠️ 注意事项

1. **不要复制 `venv/` 目录** - 每台电脑会自动创建
2. **首次启动较慢** - 需要下载 AI 模型（约 470MB）
3. **确保端口 5001 未被占用** - 或修改 `app.py` 中的端口

## 🆘 遇到问题？

查看 `部署指南.md` 的"常见问题"部分，包含所有常见问题的解决方案。
